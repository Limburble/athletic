## Anti-Patterns Verdict

**LLM assessment**: Athletic does *not* read as AI-generated slop at first glance. The design has a genuine point of view. The Bebas Neue + Fraunces italic split in the wordmark is a real typographic decision. Deliberately avoiding a circular progress ring on the timer shows restraint. The guided setup stack with active/done/locked states is a considered UX pattern.

Two patterns undermine the craft significantly:

**Glassmorphism as the default surface.** `.glass` is applied to StepCards, WorkoutBlocks, ExerciseRows, and the Nav pill — every container in the app. The impeccable design laws ban glassmorphism as a default. When every surface blurs, the blur does no compositional work; nothing floats above anything else because everything is floating.

**Ambient orbs as mood.** Three radial gradient blobs pulsing in the background is a well-worn AI dark UI trope. The timer's full-screen color flood doesn't need atmospheric support — the color IS the atmosphere.

The timer overlay — full-screen, no glass, no orbs, just phase color + enormous time digit + three controls — is where all anti-patterns disappear. It's the strongest moment and the direction the rest should push toward.

## Overall Impression

The core loop is clean and well-structured. The guided setup stack is the right pattern. The timer overlay is the app's best moment: purposeful, confident, nothing wasted.

The single biggest opportunity is the surface treatment. Strip `.glass` from everything except the one or two contexts where blur is physically meaningful, and the app's character immediately sharpens toward the "Instrument" identity described in CONTEXT.md.

## What's Working

**1. The guided setup stack.** Active/done/locked card states with animated collapse/expand is the right UX pattern for a sequential builder. Completed steps collapse to a tappable one-line summary. Cognitive load checklist: 1 failure out of 8 (muscle group count: 7 chips slightly over the working-memory limit of 4, but spatially grouped and recognizable).

**2. The timer fullscreen overlay.** Phase-colored full-screen takeover, 19–24vw Bebas Neue time digit, 2px progress strip instead of a ring, three controls with clear size hierarchy. No glass, no orbs, just color and type.

**3. Typography system.** The `.t-display` / `.t-label` / `.t-body` / `.t-caption` scale is a working system with proper size ratios. Bebas Neue reserved for display, system sans for body copy — nothing competes in between.

## Priority Issues

**[P1] Glassmorphism is the default surface grammar — everywhere**
- **What**: `.glass` class applied to StepCards, WorkoutBlocks, ExerciseRow expand panels, and the Nav pill.
- **Why it matters**: Blur homogenizes everything — no card stands out. Recognized anti-pattern in the impeccable design laws and a dominant aesthetic in AI-generated tool UIs.
- **Fix**: Replace `.glass` on StepCards and WorkoutBlocks with solid `background: var(--surface-1)`. Reserve `.glass` for the timer overlay only. Evaluate whether ambient orbs are still needed after the glass comes off.
- **Suggested command**: `$impeccable bolder src/index.css src/components/`

**[P1] No guard against building with zero muscle groups selected**
- **What**: "Build My Workout" CTA calls `compile()` with no check that `groups.length > 0`.
- **Why it matters**: Silent empty workout with no feedback.
- **Fix**: In `compile()`: if `groups.length === 0`, set `activeStep = 1`, show inline error on the muscles chip row, prevent compilation.
- **Suggested command**: `$impeccable harden src/hooks/useAppState.js src/components/BuildScreen.jsx`

**[P1] No initial `data-mode` / `data-dark` attribute on the HTML root**
- **What**: Both attributes are set by `useEffect` after first render. HTML file has neither attribute.
- **Why it matters**: CSS transitions on theme tokens fire on mount from unset → applied. Visible flash on slow devices.
- **Fix**: Add `data-mode="def" data-dark="true"` directly to `<html>` in `index.html`.
- **Suggested command**: `$impeccable harden index.html`

**[P2] Zero accessibility foundation**
- **What**: Interactive elements use `<div onClick>`. No `aria-expanded`, `aria-pressed`, `aria-label`. No `prefers-reduced-motion` guard.
- **Why it matters**: Unusable with keyboard, VoiceOver, or AssistiveTouch.
- **Fix**: Swap interactive divs for `<button>`. Add ARIA attributes throughout. Add `prefers-reduced-motion` media query to pause `orbFloat` keyframes.
- **Suggested command**: `$impeccable audit src/`

**[P2] All-or-nothing reset with no partial-step editing**
- **What**: `reset()` clears all three steps atomically. No path to change one step while preserving others.
- **Why it matters**: Regular friction for a weekly user who wants to vary just the time or just the muscles.
- **Fix**: Make `reset()` accept an optional `toStep` parameter. `reset(1)` would set `activeStep = 1` and `compiled = false` without clearing `slotIdx` or `groups`.
- **Suggested command**: `$impeccable shape src/hooks/useAppState.js`

## Persona Red Flags

**Alex (Power User — the target user)**: No saved "last session" config. No quick-repeat. No keyboard shortcuts. No preset combos. After 30 sessions the full 3-step guided setup is friction, not help. Muscle chip row has no bulk-select or preset combos like "push day" / "pull day."

**Casey (Distracted Mobile User — gym between sets)**: No "you're here" indicator in the result screen. Pre-Config HIIT button at the bottom of a scrollable list. All state is in-memory — tab reload or app kill loses the workout entirely. No "resume" prompt.

**Riley (Stress Tester)**: 0 muscle groups + "Build My Workout" = silent empty workout. HIIT `rounds = 0` has no floor check in `advancePhase`. Switching hiitMode while timer overlay is open can corrupt phase logic. Page refresh mid-timer: silent reset, no recovery.

## Minor Observations

- `ExerciseRow` info panel: `style={{ background: 'rgba(0,0,0,0.08)' }}` hardcoded — breaks in light mode. Use `var(--surface-2)`.
- `advancePhase` nests `setState` inside `setState` callback for `hiitRounds` tracking — stale closure risk in React 18 concurrent renderer. Refactor to `useReducer`.
- No `<title>` update between Build and Timer tabs.
- Tagline "Your training, structured." may be first element cut on 375px / 320px viewports with a step card expanded — worth testing.
- No `prefers-reduced-motion` guard on `orbFloat1/2/3` and `pulseScale` keyframes.
- `base: './'` in vite.config.js: verify no double-path asset resolution on Vercel now that both targets are live.
